**The code.** l = 21, m = 18, A = x^3 + y^10 + y^17, B = y^5 + x^3 + x^19, n = 756, k = 16. The qubit order is i*m + j, then the right block. We searched Z-logicals only, using d_X = d_Z.

**Our search.**
- A check-driven cluster search in C, run as iterative deepening: pass b proves that no logical is lighter than b.
- The anchors are qubits 0 and lm, by the translation argument.
- It branches on the unsatisfied check with the fewest candidates, with sibling exclusion.
- It prunes with |S| + ceil(u / maxcol), and with a disjoint-check packing bound, like your `pack`.
- It has no parity rule and no overlap rule. Evenness was applied afterwards: all column weights are odd, so every element of ker H_X has even weight.
- Each pass is split into 16 parts by a hash of the node at depth 6, on 4 cores.
