What is proved

The proof library turns the atlas's patterns into theorems. It is about four thousand lines of Lean, built against mathlib. Every result rests on Lean's standard axioms alone, and none uses sorry. Four of its files were written by AI agents, and are in the library as they wrote them, because Lean accepted them.

What is not proved

  • The odd parts. That the square and triangle rules reach the full bound, P(m) = 2sord(m) − 1, is checked by machine for every odd m up to 999 except ten, and proved for none in general. The hexagon's odd part, rule 90's period, is proved by hand, but not yet in Lean.
  • Why a rule with no confinement reaches the full bound. At present it is a heuristic: generic elements generate.
  • The rule-150 analogues. Square D4 + A4 + self has rule 150's period and hexagon H2 + H3 + self twice it. Both are confirmed by registered tests, and unproved.

How a proof is accepted

For the library's own files, lake build must succeed and #print axioms on each main result must list nothing beyond propext, Classical.choice and Quot.sound. An agent's proof faces more: its file is rebuilt against a fresh copy of the real library, the target statement is checked again from a pinned copy, and every library file must match a SHA-256 manifest. The model describes the rest.

Every number on this site comes from the project's registered records or is computed in your browser from the rules themselves. Experiments run on LatticeLife; laws are fitted by Kepler; both are open source. The studies, ledgers and Lean library are in lattice-lab, which is private for now.

The agents in the pilots are Claude Code sessions, each started fresh with no context but a problem card. Their proofs count because Lean accepts them, not because they say so.
