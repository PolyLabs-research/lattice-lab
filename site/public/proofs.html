What is proved

The proof library turns the atlas's patterns into theorems. It is about 5,300 lines of Lean, built against mathlib. Every result rests on Lean's standard axioms alone, and none uses sorry. Seven of its files were written by AI agents, and are in the library as they wrote them, because Lean accepted them: three verbatim, and four with only their namespaces renamed.

What is not proved

  • The odd parts. That the square and triangle rules reach the full bound, P(m) = 2sord(m) − 1, is checked by machine for every odd m up to 999 except ten, and proved for none in general. The hexagon's odd part, rule 90's period, is proved by hand, but not yet in Lean.
  • Why a rule with no confinement reaches the full bound. At present it is a heuristic: generic elements generate.
  • Rule 4850 at m = 37. That every nonzero eigenvalue is a ninth power has a proof from a multi-agent deep dive, which three independent checkers found stands, with repairs, and whose final chain the orchestrator rechecked by machine. It is not yet written up as one document, and not in Lean.
  • The rule-150 analogues. Square D4 + A4 + self has rule 150's period and hexagon H2 + H3 + self twice it. Both are confirmed by registered tests, and unproved.

How a proof is accepted

For the library's own files, lake build must succeed and #print axioms on each main result must list nothing beyond propext, Classical.choice and Quot.sound. An agent's proof faces more: its file is rebuilt against a fresh copy of the real library, the target statement is checked again from a pinned copy, and every library file must match a SHA-256 manifest. The model describes the rest.

Every number on this site comes from a programme's own records (its registered predictions, preregistrations, run logs and rulings) or is computed in your browser. Where a test failed, the page says so, and a result counts because a check outside the work passed it, not because the work says so.

Experiments run on LatticeLife; laws are fitted by Kepler; both are open source. The studies, with their ledgers and records, and the Lean library are in lattice-lab, which is open source too.

The agents in the pilots are Claude Code sessions, each started fresh with no context but a problem card; the seventh pilot's second round ran over the API. Their proofs count because Lean accepts them, not because they say so.
