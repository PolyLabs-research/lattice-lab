# The triangular lattices' open odd part, checked by machine

[docs/parity-lattices.md](../../docs/parity-lattices.md) proves that both triangular parity rules
have period 2 * 2^v(n) * L(m) on the n x n torus (n = 2^v m, m odd, m >= 3). L(m) is the order
of the group generated by the eigenvalues of the rule's square, and divides 2^sord(m) - 1. The
law found by Kepler and confirmed at every computed size says L(m) = 2^sord(m) - 1. That holds at
m exactly when the eigenvalues generate the whole multiplicative group of F(2^sord(m)).

`check_triangles.py` decides this for one odd m at a time. It reuses the method of
[../xor-periods-proof](../xor-periods-proof): for each prime r of 2^sord(m) - 1, it searches the
lines (p, q) of the torus for an eigenvalue that is not an r-th power. The lines cover every pair
of roots of unity, so an unresolved prime would be a counterexample. As a control it runs the
hexagon too, whose eigenvalues provably generate only rule 90's group: up to m = 199 it fails
exactly at rule 90's shortfalls, as it must.

```bash
uv run python examples/parity-lattices-proof/check_triangles.py 3 999 > results.jsonl
```

Result: see [docs/parity-lattices.md](../../docs/parity-lattices.md#the-triangles-odd-part-checked-by-machine).
